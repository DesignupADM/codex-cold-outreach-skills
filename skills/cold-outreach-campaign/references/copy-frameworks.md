# Copy Frameworks

Use this reference when writing or rewriting the email body.

## Core copy rules

- The first sentence earns the second
- The email should be skimmable in under 10 seconds
- One email, one angle, one CTA
- Specificity beats persuasion tricks
- The offer should sound easy to evaluate

## Recommended first-touch framework

Use this default sequence:

1. Personalize with purpose
2. Name the problem or opportunity
3. Present the offer or point of view
4. Add one proof point
5. End with a low-friction CTA

Example structure:

```text
[Personalized observation tied to a real business angle.]

[Why that likely matters for the buyer.]

[Specific offer or idea.]

[Short proof point or reason to trust it.]

[Simple CTA.]
```

## Alternative frameworks

### Problem -> Cost -> Offer -> CTA

Best when the prospect likely feels the pain already.

### Trigger -> Insight -> Offer -> CTA

Best when there is a recent event or company motion to anchor on.

### Proof -> Relevance -> Offer -> CTA

Best when credibility is the hardest part.

### Opportunity -> Why now -> Offer -> CTA

Best when upside sells better than pain.

## CTA guidance

Prefer CTAs that are easy to answer:

- `Open to a quick look?`
- `Worth sending a short audit?`
- `Should I send over the idea?`
- `Open to a 15-minute chat next week?`

Use meeting CTAs only when the offer already feels concrete. Otherwise ask for permission to send something short first.

## Tightening weak copy

If a draft feels generic, cut or rewrite:

- Generic compliments
- Long preambles
- Feature lists
- Adjectives without proof
- Multiple asks in the same message

If the copy feels too salesy, reduce intensity and make the value more specific.

## Tone calibration

- Enterprise: direct, credible, lower hype
- Founder-led: sharper, more conversational, still concise
- Partnerships: more collaborative and strategic
- Mid-market sales: practical, outcome-led, easy to forward

Match the user's requested tone, but keep the campaign readable and commercially grounded.
